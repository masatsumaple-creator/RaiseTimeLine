# RaiseTimeLine プロトタイプ Mock

`docs/` の要件定義書・機能一覧・機能定義書(v0.3)に基づく、HTML / CSS / JavaScript だけの画面Mockです。サーバー・DB・ビルドは不要で、データはブラウザの localStorage に保存されます。

## 起動

`mock/index.html` をブラウザで開くだけです(または `python -m http.server` で配信)。ヘッダー下の「データをリセット」で初期状態に戻せます。

## Mock での割り切り

- 未ログインでは、「全体」タブ・投稿詳細・プロフィール・フォロー一覧を閲覧できます(要件の「可(仮)」に合わせた)。検索とプロフィール編集はログインが必要で、投稿・コメント・いいね・フォローを押すとログイン画面へ移り、ログイン後に元の画面へ戻ります。
- 画像はブラウザ内でプレビュー・保存します(S3 / 署名付き URL は使いません)。サイズ・形式・枚数と、ファイルの中身(マジックナンバー)の検証は画面側で再現しています。画像が大きいと localStorage の容量を超え、リロードで消えることがあります。
- パスワードの BCrypt、CSRF、サーバー側の再検証(403 / 404)、複数端末間の同期は対象外です。
- ダミーの投稿は 52 件あり、「もっと見る」(20 件ずつ)を確認できます。
